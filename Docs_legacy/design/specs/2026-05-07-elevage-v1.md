## Principes transversaux élevage

- **Unité de temps** : 1 mois de jeu = 5 jours réels ; 1 an = 60 jours réels. Toutes les durées ci-dessous sont exprimées en **mois de jeu** (MJ) ou **jours de jeu** (JJ).
- **Tick quotidien** : chaque JJ, les stocks d'aliment décroissent, la production est calculée, les gestations progressent.
- **Bot achat animaux** : le bot vend des animaux de démarrage uniquement — quotas par atelier, qualité plafonnée (score génétique ≤ 60/100). Achat entre joueurs = marché libre sans plafond. [V2+] : vente d'animaux reproducteurs de haute qualité via bot.
- **Reproduction V1 simplifiée** : pas de génétique détaillée. Un seul paramètre `qualite_genetique` [0–100] hérité à la naissance comme moyenne des parents ± bruit aléatoire ±5.
- **Mode Normal / Expert** : bascule par atelier. Normal = conséquences visibles ; Expert = causes et détails.
- **Règle de scope** : tout ce qui dépasse le périmètre V1 est marqué **[V2+]**.

### Variables d'état communes à tous les ateliers

| Variable | Type | Description |
|---|---|---|
| `atelier_type` | enum | `bovin_lait` · `bovin_viande` · `ovin` · `porcin` · `volaille` |
| `effectif` | int | Nombre d'animaux présents |
| `capacite_max` | int | Plafond bâtiment |
| `stock_aliment_j` | float | Jours d'autonomie alimentaire restants |
| `stock_litiere_j` | float | Jours d'autonomie en litière (bovins/ovins/porcins) |
| `etat_sanitaire` | float [0–100] | Santé globale du troupeau |
| `productivite` | float [0–100] | Niveau de production courant |
| `fumier_stock_t` | float | Tonnes de fumier/lisier disponibles pour épandage |

### Dégradation passive commune

- `stock_aliment_j` : −1/JJ automatiquement.
- Si `stock_aliment_j = 0` : `productivite` −10/JJ, `etat_sanitaire` −5/JJ.
- `etat_sanitaire` : −1/JJ sans entretien (litière + soins préventifs).
- `etat_sanitaire < 30` : alerte épidémie ; mortalité possible (−1 à −3 % effectif/JJ).
- `fumier_stock_t` : +production journalière/JJ ; plafonné à capacité fosse ; débordement = malus sanitaire.

## Bovins lait

### Variables d'état

| Variable | Type | Description |
|---|---|---|
| `stade_vie` | enum | `genisse` · `vache_lactation` · `vache_tarissement` · `reforme` |
| `age_mj` | int | Âge en mois de jeu |
| `qualite_genetique` | int [0–100] | Potentiel laitier hérité |
| `production_lait_j` | float (L) | Litres produits ce JJ |
| `jours_lactation` | int | JJ depuis le dernier vêlage |
| `en_gestation` | bool | Vache gestante |
| `jours_gestation` | int | JJ de gestation écoulés |
| `nb_velages` | int | Nombre de vêlages (influence durée de vie productive) |

### Cycle de production

- **Durée cycle** : 10 MJ (gestation 6 MJ + lactation 8 MJ avec chevauchement ; tarissement 1 MJ)
- **Production** : lait, 20–35 L/vache/JJ selon `qualite_genetique` et `productivite`
- **Coût journalier** : 2,50–4,00 €/vache/JJ (alimentation + litière + charges fixes)

Chronologie type :
1. Génisse achetée → stade `genisse` (âge 0–14 MJ)
2. À 14 MJ : première insémination possible
3. Gestation : 6 MJ → vêlage → veau (vendu ou élevé)
4. Lactation : 8 MJ de production ; insémination à 2 MJ post-vêlage
5. Tarissement : 1 MJ avant vêlage suivant (production = 0)
6. Réforme recommandée après 5 vêlages (nb_velages ≥ 5)

### Règles

#### R1 — Démarrage atelier
- Prérequis : bâtiment bovin lait construit (capacité min. 5 têtes).
- Achat via bot : génisses gestantes ou vaches en lactation, qualité ≤ 60, quota 5 têtes/trimestre (quota bot — voir economy-markets-v1.md §1).
- L'atelier est actif dès qu'au moins 1 vache est en stade `vache_lactation`.

#### R2 — Alimentation
- Ration journalière : 8 kg MS fourrage + 4 kg concentré/vache/JJ (valeurs standard).
- `alimentation_factor` = `stock_aliment_j > 0` ? `min(ration_fournie / ration_requise, 1.0)` : 0.
- Fourrage peut provenir des prairies de l'exploitation (réduction coût achat).
- Alerte si `stock_aliment_j < 5`.

#### R3 — Santé
- Soins préventifs (vaccination, parage) : action mensuelle, coût fixe, maintient `etat_sanitaire`.
- Traitement vétérinaire : déclenché si `etat_sanitaire < 60` ; coût variable ; remonte +15/traitement.
- Vague de chaleur (météo > 32°C) : `etat_sanitaire` −3/JJ, `production_lait_j` −20 %.
- Grand froid (< −5°C) : coût alimentation +20 %.

#### R4 — Reproduction
- Insémination : action joueur ou ETA bot (insémination standard).
- Taux de réussite : 65 % (standard) ; `etat_sanitaire > 80` → +10 % ; `etat_sanitaire < 50` → −20 %.
- Gestation : 6 MJ. À terme : vêlage automatique → +1 veau (vendu au prix marché ou gardé).
- Veau gardé : entre en stade `genisse`, âge 0.
- Pas de jumeaux en V1. [V2+] : gestion fine de la fertilité, synchronisation des chaleurs.

#### R5 — Production
```
production_lait_j = base_race(qualite_genetique)     -- 20–35 L
                  × courbe_lactation(jours_lactation) -- pic à 60 JJ, déclin progressif
                  × alimentation_factor               -- [0 – 1]
                  × (etat_sanitaire / 100)
                  × meteo_factor                      -- canicule : 0.8
```
- Tarissement (`jours_lactation > 240` ou 1 MJ avant vêlage) : `production_lait_j = 0`.
- Lait collecté chaque JJ → stock lait (périssable, durée de vie 2 JJ sans réfrigération).

#### R6 — Vente
- Lait brut : vendu à la coop bot (prix spot) ou transformé (laiterie simple, +30–50 %).
- Veaux : vendus au marché joueur ou bot (prix selon âge/poids).
- Vaches de réforme : vendus au bot (prix viande, inférieur au marché bovin viande).
- Contrainte fraîcheur : lait non vendu/transformé sous 2 JJ → perte totale.

### Paramètres (ranges indicatifs)

| Paramètre | Facile | Standard | Exigeant |
|---|---|---|---|
| Production base (L/vache/JJ) | 28 | 25 | 22 |
| Coût alimentation (€/vache/JJ) | 2,00 | 2,50 | 3,20 |
| Taux réussite insémination | 75 % | 65 % | 55 % |
| Dégradation sanitaire sans soin (/JJ) | −0,5 | −1 | −1,5 |
| Prix lait bot (€/L) | 0,42 | 0,38 | 0,34 |
| Durée gestation (MJ) | 6 | 6 | 6 |

### Mode Normal vs Expert

- **Normal** : effectif total · litres/jour · stock aliment (jours) · état sanitaire (icône) · alerte vêlage imminent
- **Expert** : détail par vache (stade, jours lactation, production individuelle) · courbe de lactation · calendrier de reproduction · ration décomposée (fourrage/concentré) · coût/litre calculé · projection mensuelle de production

### Interactions avec autres systèmes

- **Grandes cultures / Prairies** : fourrage produit en interne réduit le coût d'alimentation acheté.
- **Sols** : lisier produit = intrant organique (fertilité +normal, MO +expert).
- **Stockage** : lait → citerne liquide (contrainte fraîcheur 2 JJ).
- **Transformation** : lait → laiterie simple (+30–50 % valeur).
- **Météo** : canicule dégrade production et santé ; grand froid augmente coût alimentation.
- **Services** : insémination standard disponible via ETA bot.
- **Marché** : prix lait soumis au spread bot + tag d'origine régionale.

## Bovins viande

### Variables d'état

| Variable | Type | Description |
|---|---|---|
| `stade_vie` | enum | `veau` · `broutard` · `bovin_croissance` · `bovin_fini` · `reforme` |
| `age_mj` | int | Âge en mois de jeu |
| `poids_kg` | float | Poids vif courant |
| `gmq_j` | float (kg/JJ) | Gain moyen quotidien effectif |
| `qualite_genetique` | int [0–100] | Potentiel de croissance hérité |
| `en_gestation` | bool | Femelle gestante (si atelier naisseur) |
| `jours_gestation` | int | JJ de gestation écoulés |

### Cycle de production

- **Durée cycle** : 14–18 MJ de la naissance à l'abattage (achat broutard à 4 MJ → finition à 14–16 MJ)
- **Production** : viande vive, gain 0,8–1,2 kg/tête/JJ en phase croissance
- **Coût journalier** : 1,80–3,00 €/tête/JJ

Chronologie type (atelier engraissement) :
1. Achat broutard (4 MJ, ~200 kg) via bot ou marché joueur
2. Phase croissance (10–12 MJ) : GMQ 0,9 kg/JJ → ~470 kg
3. Phase finition (2 MJ) : ration enrichie, GMQ réduit, dépôt gras
4. Vente à l'abattoir à poids cible 580–650 kg

Chronologie type (atelier naisseur-engraisseur) :
1. Vache allaitante → gestation 6 MJ → vêlage → veau
2. Sevrage à 3 MJ → broutard vendu ou gardé
3. Si gardé : cycle engraissement ci-dessus

### Règles

#### R1 — Démarrage atelier
- Prérequis : bâtiment bovin viande (capacité min. 5 têtes) ou prairie suffisante (≥ 1 ha/tête).
- Achat via bot : broutards uniquement, qualité ≤ 60, quota 15 têtes/commande.
- Atelier actif dès 1 animal en stade `bovin_croissance`.

#### R2 — Alimentation
- Phase croissance : fourrage + concentré (6 kg MS/tête/JJ).
- Phase finition : ration enrichie concentré (+30 %), coût +40 %.
- `alimentation_factor` = `min(ration_fournie / ration_requise, 1.0)`.
- Pâturage possible si prairie disponible : réduit coût alimentation de 40–60 % en saison.

#### R3 — Santé
- Soins préventifs mensuels (vaccination, antiparasitaire).
- Traitement si `etat_sanitaire < 60` : coût variable, +15 santé.
- Stress thermique (> 30°C) : GMQ −15 % ; grand froid (< −5°C) : coût alimentation +15 %.

#### R4 — Reproduction (atelier naisseur uniquement)
- Même mécanique que bovins lait : insémination ou saillie naturelle (taureau = coût fixe mensuel).
- Gestation : 6 MJ. Vêlage → veau stade `veau`.
- Taux de réussite : 70 % standard.
- [V2+] : gestion du troupeau allaitant avec saisonnalité des vêlages.

#### R5 — Production
```
gmq_effectif = gmq_base(qualite_genetique, stade)   -- 0.8–1.2 kg/JJ
             × alimentation_factor
             × (etat_sanitaire / 100)
             × meteo_factor

poids_kg += gmq_effectif chaque JJ
```
- Stade `bovin_fini` atteint quand `poids_kg ≥ poids_cible` (580–650 kg selon race).
- Rentabilité différée : aucun revenu pendant 10–14 MJ ; coûts fixes s'accumulent.

#### R6 — Vente
- Vente à l'abattoir (bot ou marché joueur) quand stade `bovin_fini`.
- Prix = `poids_carcasse_kg × prix_kg_carcasse` ; rendement carcasse ≈ 55–60 % du poids vif.
- Vente hors poids cible possible mais décotée (−10 à −20 %).
- Vaches de réforme : vendues au bot (prix inférieur).

### Paramètres (ranges indicatifs)

| Paramètre | Facile | Standard | Exigeant |
|---|---|---|---|
| GMQ base (kg/JJ) | 1,1 | 0,95 | 0,80 |
| Coût alimentation (€/tête/JJ) | 1,60 | 2,00 | 2,60 |
| Poids cible abattage (kg) | 600 | 620 | 650 |
| Prix carcasse bot (€/kg) | 4,20 | 3,90 | 3,60 |
| Dégradation sanitaire sans soin (/JJ) | −0,5 | −1 | −1,5 |

### Mode Normal vs Expert

- **Normal** : effectif · poids moyen du lot · stock aliment (jours) · état sanitaire · estimation date vente
- **Expert** : détail par lot (stade, poids individuel, GMQ courant) · courbe de croissance · coût cumulé/tête · marge estimée à l'abattage · calendrier de finition

### Interactions avec autres systèmes

- **Grandes cultures / Prairies** : pâturage et fourrage réduisent le coût d'alimentation.
- **Sols** : fumier = intrant organique parcelles.
- **Stockage** : pas de contrainte fraîcheur (vente directe à l'abattoir).
- **Météo** : chaleur réduit GMQ ; froid augmente coût alimentation.
- **Marché** : prix vif soumis au spread bot + tag d'origine ; rentabilité différée = risque de marché.
- **Services** : ETA bot pour insémination (atelier naisseur).

## Ovins

### Variables d'état

| Variable | Type | Description |
|---|---|---|
| `stade_vie` | enum | `agneau` · `agneau_engraissement` · `brebis_adulte` · `belier` · `reforme` |
| `age_mj` | int | Âge en mois de jeu |
| `poids_kg` | float | Poids vif courant |
| `qualite_genetique` | int [0–100] | Potentiel de croissance / laine |
| `en_gestation` | bool | Brebis gestante |
| `jours_gestation` | int | JJ de gestation écoulés |
| `tonte_due` | bool | Tonte à réaliser (cycle annuel) |

### Cycle de production

- **Durée cycle** : 5–6 MJ de la naissance à la vente agneau ; tonte annuelle (1×/an)
- **Production** : agneaux (viande), 18–25 kg carcasse/agneau ; laine, 3–5 kg/brebis/an
- **Coût journalier** : 0,40–0,80 €/tête/JJ

Chronologie type :
1. Brebis adulte → lutte (saillie) en automne (MJ 7–8)
2. Gestation : 3 MJ → agnelage (MJ 10–11)
3. Allaitement : 1,5 MJ → sevrage
4. Agneau engraissement : 2–3 MJ → vente à 35–45 kg vif
5. Tonte brebis : 1×/an (printemps, MJ 4–5)

### Règles

#### R1 — Démarrage atelier
- Prérequis : bâtiment ovin ou prairie clôturée (≥ 0,5 ha/5 brebis).
- Achat via bot : brebis adultes ou agnelles, qualité ≤ 60, quota 30 têtes/commande.
- Atelier actif dès 1 brebis adulte présente.

#### R2 — Alimentation
- Pâturage principal en saison (printemps–automne) : coût quasi nul si prairie disponible.
- Complémentation hivernale : foin + concentré, 1,5 kg MS/tête/JJ.
- `alimentation_factor` = pâturage disponible ? 0,9 : `min(ration_fournie / ration_requise, 1.0)`.

#### R3 — Santé
- Soins préventifs : vermifugation (2×/an), vaccination.
- Sensibilité aux parasites gastro-intestinaux : `pression_parasitaire` augmente si pâturage intensif sans rotation.
- Traitement si `etat_sanitaire < 60` : coût faible (ovins moins coûteux que bovins).
- Gel prolongé (< −10°C) : risque mortalité agneaux nouveau-nés (+alerte).

#### R4 — Reproduction
- Lutte naturelle (bélier présent) ou insémination (ETA bot).
- Saisonnalité : lutte en automne (MJ 7–9) ; agnelage en hiver–printemps (MJ 10–12).
- Prolificité : 1,3 agneau/brebis/an en moyenne (V1 simplifié : 1 ou 2 agneaux par tirage aléatoire).
- Gestation : 3 MJ.
- [V2+] : gestion de la saisonnalité fine, synchronisation des chaleurs, races à prolificité élevée.

#### R5 — Production
```
gmq_agneau = gmq_base(qualite_genetique)   -- 0.25–0.35 kg/JJ
           × alimentation_factor
           × (etat_sanitaire / 100)

poids_kg += gmq_agneau chaque JJ (stade agneau_engraissement)
```
- Tonte : action joueur 1×/an → collecte `laine_kg = 3 + qualite_genetique × 0.02` kg/brebis.
- Laine vendue au bot (valeur faible) ou stockée. [V2+] : filière laine valorisée.

#### R6 — Vente
- Agneaux : vendus à l'abattoir (bot ou marché) à 35–45 kg vif ; prix saisonnier (pic Pâques/Aïd).
- Brebis de réforme : vendues au bot (prix bas).
- Laine : vendue au bot (prix fixe faible, valeur symbolique en V1).

### Paramètres (ranges indicatifs)

| Paramètre | Facile | Standard | Exigeant |
|---|---|---|---|
| GMQ agneau (kg/JJ) | 0,32 | 0,28 | 0,24 |
| Coût alimentation hiver (€/tête/JJ) | 0,35 | 0,50 | 0,65 |
| Prolificité (agneaux/brebis) | 1,5 | 1,3 | 1,1 |
| Prix agneau bot (€/kg vif) | 3,80 | 3,40 | 3,00 |
| Dégradation sanitaire sans soin (/JJ) | −0,5 | −1 | −1,5 |

### Mode Normal vs Expert

- **Normal** : effectif · agneaux en cours · stock aliment · état sanitaire · alerte tonte / agnelage imminent
- **Expert** : détail par lot (stade, poids, GMQ) · calendrier de lutte et agnelage · pression parasitaire · coût/agneau produit · marge estimée

### Interactions avec autres systèmes

- **Prairies / Foncier** : pâturage extensif = coût alimentation minimal ; rotation des parcelles réduit pression parasitaire.
- **Sols** : déjections = fertilisation organique prairies.
- **Météo** : gel hivernal = risque mortalité agneaux ; sécheresse = manque de pâturage → coût alimentation augmente.
- **Marché** : prix agneaux saisonnier (événement calendaire Pâques/Aïd = pic de prix).
- **Services** : insémination via ETA bot possible.

## Porcins

### Variables d'état

| Variable | Type | Description |
|---|---|---|
| `stade_vie` | enum | `porcelet` · `porc_croissance` · `porc_finition` · `truie_adulte` · `verrat` · `reforme` |
| `age_mj` | int | Âge en mois de jeu |
| `poids_kg` | float | Poids vif courant |
| `qualite_genetique` | int [0–100] | Potentiel de croissance |
| `en_gestation` | bool | Truie gestante |
| `jours_gestation` | int | JJ de gestation écoulés |
| `nb_porcelets_portee` | int | Taille de la portée en cours |

### Cycle de production

- **Durée cycle** : 5–6 MJ de la naissance à l'abattage (achat porcelet à 1 MJ → vente à 5–6 MJ)
- **Production** : viande, gain 0,7–0,9 kg/tête/JJ ; poids abattage 110–130 kg
- **Coût journalier** : 0,80–1,40 €/tête/JJ

Chronologie type (atelier naisseur-engraisseur) :
1. Truie adulte → saillie/insémination
2. Gestation : 2,5 MJ → mise bas → 10–12 porcelets
3. Allaitement : 1 MJ → sevrage → porcelets en croissance
4. Croissance : 2 MJ (25 → 70 kg)
5. Finition : 1,5 MJ (70 → 115 kg) → abattage

Chronologie type (atelier engraissement seul) :
1. Achat porcelets sevrés (bot, ~25 kg)
2. Croissance + finition : 3,5 MJ → abattage

### Règles

#### R1 — Démarrage atelier
- Prérequis : bâtiment porcin (porcherie) avec cases séparées croissance/finition.
- Achat via bot : porcelets sevrés uniquement, qualité ≤ 60, quota 50 têtes/commande.
- Atelier actif dès 1 porc en stade `porc_croissance`.

#### R2 — Alimentation
- Ration précise par stade : croissance 2,2 kg aliment/JJ ; finition 2,8 kg/JJ.
- Aliment composé (céréales + protéines) : peut être produit en interne (meunerie) ou acheté.
- `alimentation_factor` = `min(ration_fournie / ration_requise, 1.0)`.
- Sous-alimentation : GMQ chute rapidement (−30 % si factor < 0,8).

#### R3 — Santé
- Sensibilité élevée aux maladies respiratoires et digestives.
- Soins préventifs : vaccination, biosécurité (nettoyage cases).
- Traitement si `etat_sanitaire < 60` : coût modéré.
- Chaleur (> 28°C) : stress thermique fort → GMQ −20 %, `etat_sanitaire` −2/JJ.
- Ventilation bâtiment : réduit l'impact thermique (investissement bâtiment).

#### R4 — Reproduction
- Insémination artificielle (ETA bot) ou verrat présent (coût fixe mensuel).
- Gestation : 2,5 MJ. Mise bas → 10–12 porcelets (V1 : tirage [9–13]).
- Taux de réussite insémination : 80 % standard.
- Intervalle sevrage–saillie : 0,5 MJ → 2,2 portées/truie/an possible.
- [V2+] : gestion bande, synchronisation, optimisation du nombre de truies.

#### R5 — Production
```
gmq_effectif = gmq_base(qualite_genetique, stade)   -- 0.7–0.9 kg/JJ
             × alimentation_factor
             × (etat_sanitaire / 100)
             × meteo_factor                          -- chaleur : 0.8

poids_kg += gmq_effectif chaque JJ
```
- Stade `porc_finition` : `poids_kg ≥ 70 kg`.
- Stade prêt à l'abattage : `poids_kg ≥ 110 kg`.
- Lisier produit : 6–8 L/porc/JJ → stock lisier (intrant organique).

#### R6 — Vente
- Vente à l'abattoir (bot ou marché joueur) à poids cible 110–130 kg.
- Prix = `poids_carcasse × prix_kg` ; rendement carcasse ≈ 78–80 % du poids vif.
- Vente hors fenêtre de poids : décote si sur-engraissé (> 135 kg).
- Truies de réforme : vendues au bot.

### Paramètres (ranges indicatifs)

| Paramètre | Facile | Standard | Exigeant |
|---|---|---|---|
| GMQ base (kg/JJ) | 0,88 | 0,80 | 0,70 |
| Coût alimentation (€/tête/JJ) | 0,70 | 0,90 | 1,20 |
| Taille portée moyenne | 11,5 | 10,5 | 9,5 |
| Prix carcasse bot (€/kg) | 1,80 | 1,65 | 1,50 |
| Dégradation sanitaire sans soin (/JJ) | −0,8 | −1,2 | −1,8 |

### Mode Normal vs Expert

- **Normal** : effectif · poids moyen lot · stock aliment (jours) · état sanitaire · estimation date abattage
- **Expert** : détail par case/lot (stade, poids, GMQ, IC) · courbe de croissance · coût aliment/kg produit · marge estimée · calendrier truies (gestation, mise bas, sevrage)

### Interactions avec autres systèmes

- **Grandes cultures** : céréales produites en interne → aliment porcin (meunerie simple, réduction coût).
- **Sols** : lisier = intrant organique à forte valeur azotée.
- **Transformation** : viande porcine → découpe standard (chaîne V1). [V2+] : charcuterie, salaisons.
- **Météo** : chaleur estivale = risque majeur ; ventilation bâtiment = investissement clé.
- **Marché** : prix porc soumis au spread bot ; cycles de prix porcins (volatilité modérée).
- **Services** : insémination via ETA bot.

## Volailles

### Variables d'état

| Variable | Type | Description |
|---|---|---|
| `type_volaille` | enum | `poulet_chair` · `poule_pondeuse` · `dinde` |
| `stade_vie` | enum | `poussin` · `croissance` · `productif` · `reforme` |
| `age_jj` | int | Âge en jours de jeu |
| `effectif_lot` | int | Taille du lot (volailles gérées par lot homogène) |
| `taux_ponte` | float [0–1] | Taux de ponte journalier (poules pondeuses uniquement) |
| `poids_kg` | float | Poids moyen du lot (poulet chair / dinde) |
| `mortalite_lot` | float [0–1] | Taux de mortalité cumulé du lot |

### Cycle de production

**Poulet chair :**
- **Durée cycle** : 1,5 MJ (42 JJ) de la mise en place à l'abattage
- **Production** : viande, gain 60–70 g/tête/JJ ; poids abattage 2,2–2,5 kg
- **Coût journalier** : 0,05–0,10 €/tête/JJ

**Poule pondeuse :**
- **Durée cycle** : 12 MJ de ponte (pic à 2 MJ, déclin progressif) ; réforme à 14–15 MJ
- **Production** : œufs, 0,85–0,95 œuf/poule/JJ en pic ; production quasi-quotidienne
- **Coût journalier** : 0,08–0,14 €/poule/JJ

**Dinde :**
- **Durée cycle** : 3–4 MJ de la mise en place à l'abattage
- **Production** : viande, gain 80–100 g/tête/JJ ; poids abattage 8–12 kg
- **Coût journalier** : 0,12–0,20 €/tête/JJ

### Règles

#### R1 — Démarrage atelier
- Prérequis : bâtiment volailles (poulailler) avec densité réglementaire (22 kg/m² poulet chair).
- Achat via bot : poussins d'un jour ou poulettes prêtes à pondre, qualité ≤ 60, quota 500 têtes/commande.
- Gestion par **lots homogènes** : tout le lot entre et sort ensemble (all-in/all-out).
- Atelier actif dès 1 lot en stade `croissance` ou `productif`.

#### R2 — Alimentation
- Aliment granulé spécifique par stade (démarrage / croissance / finition).
- Consommation : 100–180 g/tête/JJ selon stade et type.
- `alimentation_factor` = `min(ration_fournie / ration_requise, 1.0)`.
- Rupture d'aliment : mortalité +0,5 %/JJ, GMQ −50 %.
- Aliment peut provenir de la meunerie interne (céréales transformées).

#### R3 — Santé
- Sensibilité très élevée aux maladies (Newcastle, bronchite infectieuse).
- Biosécurité : action préventive hebdomadaire (nettoyage, désinfection entre lots).
- Traitement si `etat_sanitaire < 60` : coût faible mais efficacité limitée (mortalité possible).
- Chaleur (> 30°C) : mortalité +1 %/JJ si ventilation insuffisante.
- Vide sanitaire obligatoire entre lots : 0,5 MJ (10 JJ) → `etat_sanitaire` remis à 90.
- [V2+] : suivi épidémiologique, alertes sanitaires régionales, plans de biosécurité avancés.

#### R4 — Reproduction
- **Non applicable en V1** pour les ateliers chair et ponte : achat de poussins/poulettes via bot à chaque lot.
- Pas de reproduction en atelier volailles V1 (couvoirs = [V2+]).
- [V2+] : couvoir intégré, sélection de souches, autorenouvellement du troupeau.

#### R5 — Production

**Poulet chair / Dinde :**
```
gmq_effectif = gmq_base(type, age_jj)        -- courbe sigmoïde
             × alimentation_factor
             × (etat_sanitaire / 100)
             × meteo_factor                   -- chaleur : 0.85

poids_kg += gmq_effectif chaque JJ
effectif_lot × (1 - mortalite_cumul)         -- effectif réel
```

**Poule pondeuse :**
```
oeufs_jour = effectif_lot
           × taux_ponte(age_jj)              -- courbe : pic 95 % à 30 JJ, déclin à 70 % à 360 JJ
           × alimentation_factor
           × (etat_sanitaire / 100)
```
- Œufs collectés chaque JJ → stock œufs (périssable, 7 JJ sans réfrigération).
- Production quasi-quotidienne = retour économique le plus fréquent de tous les ateliers.

#### R6 — Vente
- **Poulet chair / Dinde** : vente lot entier à l'abattoir (bot ou marché) à poids cible.
  - Prix = `effectif_réel × poids_kg × prix_kg_vif`.
  - Vente hors fenêtre : sur-engraissement → décote.
- **Œufs** : vente quotidienne ou par lot (bot ou marché joueur).
  - Prix unitaire bot fixe ; marché joueur = prix variable.
  - Contrainte fraîcheur : 7 JJ sans réfrigération, 21 JJ avec chambre froide.
- Vide sanitaire entre lots : 0,5 MJ sans production ni revenu.

### Mode Normal vs Expert

- **Normal** : effectif lot · production jour (œufs ou kg estimé) · stock aliment (jours) · état sanitaire · jours avant abattage / fin de ponte · alerte vide sanitaire
- **Expert** : courbe de croissance / ponte par lot · taux de mortalité cumulé · indice de consommation (IC) · coût/kg produit · comparaison rentabilité par type de volaille · planning des lots (rotation poulailler)

### Interactions avec autres systèmes

- **Grandes cultures** : céréales → aliment volailles via meunerie (réduction coût significative).
- **Sols** : fientes = engrais organique (azote élevé, épandage à doser).
- **Stockage** : œufs → chambre froide (contrainte fraîcheur 7 JJ sans, 21 JJ avec).
- **Météo** : chaleur estivale = risque mortalité majeur ; ventilation bâtiment = investissement prioritaire.
- **Marché** : œufs = produit à prix stable (faible volatilité) ; poulet chair = prix plus volatil.
- **Services** : pas d'insémination bot (reproduction non applicable V1).

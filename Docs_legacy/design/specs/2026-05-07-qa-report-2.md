#### [M1] catalogue-cultures — Prix marché incohérents avec economy-markets-v1 Annexe A

**Source de conflit** : `economy-markets-v1.md` Annexe A vs `catalogue-cultures-v1.md` tableaux de prix.

| Produit | Prix marché ref (catalogue-cultures) | Prix marché cible (economy-markets) | Écart |
|---------|--------------------------------------|-------------------------------------|-------|
| Blé tendre | 210 €/t | 200–260 €/t | ✅ dans la fourchette |
| Orge | 190 €/t | 185–240 €/t | ✅ dans la fourchette |
| Colza | 440 €/t | 480–600 €/t | ❌ **sous le plancher de 40 €/t** |
| Maïs | 200 €/t | 210–270 €/t | ❌ **sous le plancher de 10 €/t** |
| Tournesol | 440 €/t | 510–640 €/t | ❌ **sous le plancher de 70 €/t** |
| Betterave | 33 €/t | 35–50 €/t | ❌ **sous le plancher de 2 €/t** |

Les prix `prix_marche_ref` du catalogue-cultures sont les prix de référence joueur. Ils doivent être **dans la fourchette** définie par economy-markets. Colza, maïs, tournesol et betterave sont en dessous du plancher de la fourchette economy-markets.

> **Correction appliquée** : voir section "Corrections mineures" — les valeurs sont ajustées dans le catalogue-cultures.

#### [M3] catalogue-cultures — Durées cultures vs décision compact "Durées cultures"

Le decisions_log_compact fixe : **Courte = 2 mois, Moyenne = 3–4 mois, Longue = 5–6 mois**.

Le catalogue-cultures introduit des durées hors de cette grille :

| Culture | Durée catalogue | Catégorie compact | Problème |
|---------|----------------|-------------------|---------|
| Blé d'hiver | 9 mois | — | ❌ Hors grille (max = 6 mois) |
| Orge d'hiver | 8 mois | — | ❌ Hors grille |
| Colza | 10 mois | — | ❌ Hors grille |
| Betterave | 7 mois | — | ❌ Hors grille |
| Maïs | 5 mois | Longue | ✅ |
| Tournesol | 5 mois | Longue | ✅ |
| Soja | 5 mois | Longue | ✅ |
| Orge de printemps | 4 mois | Moyenne | ✅ |
| Carotte | 3 mois | Moyenne | ✅ |
| Haricot vert | 2 mois | Courte | ✅ |
| Salade | 2 mois | Courte | ✅ |

**Analyse** : la grille compact (2/3-4/5-6 mois) semble avoir été définie pour le maraîchage et les cultures de printemps. Les grandes cultures d'hiver (blé, orge, colza) ont des cycles biologiques de 8–10 mois qui ne rentrent pas dans cette grille. La grille compact est probablement incomplète plutôt qu'en conflit direct — elle ne mentionne pas de catégorie "très longue" pour les cultures d'hiver.

> **Recommandation** : ajouter une catégorie **"Très longue : 7–10 mois"** dans decisions_log_compact pour les grandes cultures d'hiver. Pas de correction dans le catalogue (les durées biologiques sont correctes).

#### [M4] fiches-territoire — Libellés de difficulté incohérents avec territoire-foncier-v1

`territoire-foncier-v1.md §1` utilise l'enum `{ facile, moyen, difficile, expert }`.

`fiches-territoire-v1.md` utilise `{ facile, standard, expert }` — le niveau **"standard"** remplace **"moyen"** et **"difficile"** est absent.

| Région | fiches-territoire | territoire-foncier |
|--------|------------------|--------------------|
| R1 | facile | facile ✅ |
| R2 | facile | facile ✅ |
| R3 | standard | moyen ❌ |
| R4 | standard | moyen ❌ |
| R5 | standard | difficile ❌ |
| R6 | standard | moyen ❌ |
| R7 | expert | difficile ❌ |
| R8 | expert | expert ✅ |

Le decisions_log_compact mentionne `presets facile/standard/exigeant` pour la difficulté. `territoire-foncier-v1` utilise un enum différent (`moyen/difficile`). Il y a une incohérence entre les deux specs de référence elles-mêmes.

> **Recommandation** : aligner sur `{ facile, standard, exigeant }` (decisions_log_compact fait autorité). `territoire-foncier-v1` doit être corrigé (hors scope de ce rapport). `fiches-territoire-v1` est conforme au compact.

#### [M5] fiches-territoire — R1 bonus_culture_principale incohérent avec les fiches détaillées

Dans le tableau récapitulatif de `fiches-territoire-v1`, R1 affiche `bonus_culture_principale = +12 %` mais les fiches détaillées de R1 montrent des bonus de +10 % (maïs), +8 % (blé), +8 % (colza), +15 % (prairies), +12 % (maïs fourrage). Le paramètre `bonus_culture_principale` est donc ambigu : il ne correspond à aucune valeur unique dans la fiche.

> **Recommandation** : clarifier que `bonus_culture_principale` représente le bonus de la culture la plus favorisée (prairies = +15 % pour R1). Corriger le tableau récap R1 de +12 % à +15 %.

### 🟡 Mineurs

#### [m1] catalogue-cultures — Régions mal nommées dans les fiches cultures

Les fiches cultures utilisent des noms de régions incohérents avec les IDs officiels R1–R8 :

| Fiche | Libellé utilisé | ID correct |
|-------|----------------|------------|
| Blé, Colza, Orge | "R1 (Méditerranée)" | R1 = Grand Ouest ; R7 = Méditerranée |
| Maïs, Tournesol, Soja | "R1 (Méditerranée)" | idem |
| Maïs | "R4 (Atlantique / Sud-Ouest)" | R4 = Sud-Ouest ✅ mais "Atlantique" n'est pas le nom officiel |

Les fiches cultures semblent avoir utilisé une numérotation différente de celle de `territoire-foncier-v1` et `fiches-territoire-v1`. R1 est systématiquement appelé "Méditerranée" dans le catalogue alors que R1 = Grand Ouest et R7 = Méditerranée.

> **Impact** : les bonus régionaux dans le catalogue sont potentiellement inversés pour plusieurs cultures. À corriger avant implémentation.

#### [m2] catalogue-cultures — Dégradation stock légumes vs economy-markets-v1 §3

`economy-markets-v1 §3` indique `stock_degradation_rate (légumes frais) = 2–4 pts/jour`.

`catalogue-cultures-v1` indique :
- Carotte : 1,5 pts/jour ❌ (sous le plancher de 2)
- Haricot vert : 4,0 pts/jour ✅
- Salade : 5,0 pts/jour ❌ (au-dessus du plafond de 4)

> **Recommandation** : soit ajuster carotte à 2,0 pts/jour et salade à 4,0 pts/jour, soit élargir la fourchette dans economy-markets à `1,5–5,0 pts/jour` pour couvrir la diversité maraîchère. La deuxième option est préférable (plus réaliste agronomiquement).

#### [m4] elevage-v1 — Durée gestation bovins en jours réels vs mois de jeu

`elevage-v1` indique gestation bovins = **6 MJ** (mois de jeu) = 30 jours réels.

La gestation bovine réelle est ~280 jours. Avec la temporalité 1 mois = 5j réels, 6 MJ = 30j réels. C'est cohérent avec la compression temporelle du jeu. Pas d'incohérence — mais la spec devrait mentionner explicitement que cette durée est volontairement compressée (comme elle le fait pour la temporalité générale). Actuellement seul le cycle global est mentionné, pas la justification de la compression gestation.

> **Recommandation** : ajouter une note dans elevage-v1 §Bovins lait R4 : "Durée compressée par la temporalité jeu (1 MJ = 5j réels)."

---

#### [m5] elevage-v1 — Quota animaux bot incohérent avec economy-markets-v1 §1 R5

`economy-markets-v1 §1` paramètres : `animal_quota_max (bovins) = 5 têtes / trimestre`.

`elevage-v1` §Bovins lait R1 : `quota 20 têtes/commande` ; §Bovins viande R1 : `quota 15 têtes/commande`.

Le quota economy-markets est **par trimestre** (période), celui d'elevage-v1 est **par commande**. Ce sont des unités différentes mais potentiellement contradictoires : 20 têtes/commande > 5 têtes/trimestre.

> **Recommandation** : aligner les unités. Soit economy-markets passe à "par commande", soit elevage-v1 précise "quota cumulé sur la période = 20 têtes max". La valeur de 5 têtes/trimestre dans economy-markets semble très restrictive pour lancer un atelier viable — à revoir lors du calibrage.

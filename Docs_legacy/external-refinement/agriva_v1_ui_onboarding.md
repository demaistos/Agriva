# Agriva — V1 UI/UX & Onboarding

## Objet
Résumé des décisions V1 sur l’interface, l’expérience utilisateur, les workflows quotidiens et l’onboarding.

## Densité d’information V1
- Option : **B. Synthétique avec détails sur demande**.
- Principes :
  - écrans principaux = peu de métriques : argent, travail dispo, météo, file de tâches, alertes critiques ;
  - détails (parcelles, lots, agronomie, historiques) accessibles via panneaux secondaires ou mode expert.

## Normal / Expert en UI
- Normal : vues synthétiques, peu de colonnes, pas de jargon.
- Expert : colonnes et panneaux supplémentaires, avec indicateurs techniques détaillés.

## Workflows quotidiens (référence rapide)
- Jour “normal” : écran principal → météo → file de tâches → marché → éventuellement rapports rapides.
- Jour “crise” : alerte → diagnostic simple/détaillé → ajustement de file → marché → éventuellement prestataires.
- Jour “investissement” : rapports → territoire → marché → décision.

## Onboarding V1
- Option : **B. Missions progressives + conseils contextuels légers**.
- Pas de gros tutoriel bloquant :
  - séries de “premiers parcours” (première culture, première vente, première année, etc.) ;
  - bulles d’aide, surlignages, mini-checklists ;
  - possibilité de désactiver certains éléments d’aide.
- Modules experts proposés seulement après que le joueur a manipulé le système concerné en mode normal.

# Agriva — V1 Economy & Markets

## Objet
Résumé des décisions V1 sur l’économie, le bot, le marché joueur, le stockage et les objectifs/classements.

## Type d’économie V1
- Type : **joueur dominant avec bot de secours**.
- Rôle du bot : **filet de sécurité** (liquidité, amortisseur, anti-blocage), jamais plus rentable que le marché joueur.

## Marché bot
- Prix : bornés avec **spread achat/vente** et rendements décroissants sur gros volumes.
- Animaux : bot surtout pour **démarrer** un atelier, pas pour la croissance optimale.
- Bot ne doit jamais permettre une boucle d’arbitrage profitable.

## Marché joueur
- Portée : **national**, modulé par logistique (coût + délai).
- Fonction : principal lieu de création de valeur, d’optimisation et de stratégie.
- Interface : filtres puissants (type, quantité, prix, origine, délai, éventuellement qualité/réputation en V2+).

## Stockage & logistique (rappel)
- Stockage : contrainte moyenne structurante (capacités limitées mais améliorables).
- Logistique : coût + délai ; détails fins (tournées, camions, routes) réservés à V2+.

## Objectifs, classements et succès V1
- Classements :
  - segmentés par **mode (Normal/Expert)** et par **grande activité** (grandes cultures, élevage, maraîchage) ;
  - récompenses surtout cosmétiques / symboliques pour ne pas casser l’économie.
- Succès :
  - quelques succès principaux (première récolte, première année positive, première diversification…) ;
  - rôle : cosmétiques + jalons de progression, sans bonus économiques lourds.

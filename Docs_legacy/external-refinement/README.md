# Agriva Export Package — Quick Start

1. Open `manifest.json`.
2. Read `agriva_index.md`.
3. Load `agriva_agents_roles.md` into your orchestrator.
4. For design work, assign:
   - `agriva_v1_core_design.md` to the core guardian,
   - `agriva_v1_systems_farming.md` to farming systems,
   - `agriva_v1_economy_markets.md` to economy/markets,
   - `agriva_v1_ui_onboarding.md` to UI/UX,
   - `agriva_v1_social_meta.md` to social/meta.
5. Use `agriva_document_complet_long.md` as the source of truth.
6. Use `agriva_decisions_log.md` to store V1 decisions.

# Agriva — V1 Core Design

## Objet
Résumé des décisions V1 centrales : vision, piliers, boucle de jeu, difficulté, progression, risques.

## Vision et piliers
- Jeu de gestion agricole **accessible mais profond**, ancré dans le territoire français.
- Le jeu ne doit pas devenir un second travail.
- Piliers : lisibilité en mode normal, profondeur modulaire en expert, territoire comme système, importance de la planification, économie hybride vivante, progression par maîtrise (pas par clics), complexité progressive.

## Boucle de jeu
- Boucle principale : **observer → évaluer → planifier → réserver → exécuter → vendre/acheter → investir → progresser**.
- Rythme cible : boucle **quotidienne** claire, avec niveaux saisonnier et annuel en arrière-plan.

## Normal / Expert V1
- **Organisation** : bascule **par système**, avec un profil global (Normal/Expert) servant de preset.
- Normal = conséquences ; Expert = causes détaillées.
- Chaque système (sols, économie, élevage, matériel, marchés, logistique) peut être joué en normal ou expert indépendamment.

## Difficulté V1
- **Presets** : facile, standard, exigeant.
- Ces presets modulent surtout la générosité des filets de sécurité (bot, aides, risques), sans changer les règles de simulation.
- Les classements compétitifs reposent sur standard / exigeant, pas sur facile.

## Progression V1
- Axe retenu : **agrandissement + spécialisation + diversification**, introduits progressivement.
- Chemin type :
  - Année 1 : prise en main + activité principale (grandes cultures ou élevage).
  - Années 2–3 : agrandissement modéré + début de spécialisation.
  - Suite : diversification maîtrisée (ex. ajout de maraîchage ou atelier complémentaire) et montée en gamme (réputation, qualité).

## Risques V1
- Intensité : **présents mais lisibles**.
- Types : météo, prix, pannes, santé animale, trésorerie, logistique.
- Principes :
  - signaux avant-coureurs et alertes ;
  - leviers d’atténuation (assurance, diversification, stockage, contrats) ;
  - éviter les punitions surprises et arbitraires.

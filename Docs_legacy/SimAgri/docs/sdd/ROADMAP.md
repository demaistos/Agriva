# ROADMAP — Phases de développement

> Alignée sur TODO.md (35 steps). Voir SPECS.md pour les spécifications complètes.

## Phase A — MVP Jouable (Steps 0-7, ~5-7 semaines)
Fondations + temps + météo + parcelles + cultures basiques + stockage + matériel + bâtiments.
→ Un joueur peut s'inscrire, acheter une parcelle, semer du blé, récolter, stocker, vendre.

## Phase B — Élevage + Économie (Steps 8-14, ~5-7 semaines)
Rendement complet + bovins + litière/fumier/traite + pâturage + reproduction + employés + prix dynamiques + annonces.
→ Un joueur peut élever des bovins, produire du lait, vendre entre joueurs.

## Phase C — Contenu complet (Steps 15-22, ~6-8 semaines)
Matériel avancé + sol 6 éléments + 25+ cultures + 13 espèces animales + génétique/IVRAD + élevage industriel + compostage + irrigation + arboriculture + haies.
→ Toutes les mécaniques de jeu de base sont implémentées.

## Phase D — Multijoueur avancé (Steps 23-28, ~6-8 semaines)
WebSocket + messagerie + concessionnaire + transporteur + CIA + CAR + ETA.
→ Économie multijoueur complète avec métiers annexes.

## Phase E — Transformations + Lancement (Steps 29-34, ~6-8 semaines)
Fromagerie + maraîchage + foie gras + viticulture + foresterie + social complet + SimPass + multi-serveurs + déploiement.
→ Jeu complet, prêt pour le lancement.

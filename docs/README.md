# Agriva — Documentation

Structure de la documentation projet.

```
docs/
├── foundation/       # Documents fondateurs (vision, principes, objectifs)
├── design/           # Game Design Documents (GDD)
├── technical/        # Architecture, stack, ADR
├── specs/            # Spécifications fonctionnelles détaillées
├── decisions/        # Log des décisions prises (ADR léger)
├── research/         # Analyse concurrence, benchmarks, références
└── sprints/          # Planning et suivi par sprint
```

## Règle

Tout document doit être :
- Daté (YYYY-MM-DD dans le nom ou en en-tête)
- Versionné (v1, v2... ou statut draft/validé)
- Référencé depuis l'index si c'est un document actif

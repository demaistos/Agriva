# Agriva — Environnement IA

Ce dossier contient tout ce qui permet aux agents IA de travailler efficacement sur le projet.

```
.ai/
├── prompts/          # Prompts systèmes par rôle (game-designer, architect, dev, reviewer)
├── rules.md          # Règles et conventions que tout agent doit suivre
├── context.md        # Contexte projet résumé pour amorcer une session
└── workflows/        # Workflows type (design → spec → implem → review)
```

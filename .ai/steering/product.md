# Product — Agriva

## Projet

Agriva est un jeu de simulation agricole multijoueur par navigateur. On reconstruit SimAgri sur une stack moderne avec la même profondeur et couverture fonctionnelle.

## Utilisateurs cibles

- Joueurs PC nostalgiques de SimAgri
- Amateurs de jeux de gestion/simulation
- Adultes avec peu de temps — le jeu ne punit pas l'absence

## Objectifs

- Parité fonctionnelle avec SimAgri (119 sous-systèmes)
- UX moderne et responsive
- Économie vivante entre joueurs
- Progression longue durée (mois/années)

## Statut

Phase de cadrage. Pas de code encore. On construit la documentation de référence (réalité agricole) avant de coder.
